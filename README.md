# 3. House Price Prediction — README.md

A regression-based Machine Learning project that predicts house prices using property features.

## Project Overview

The objective is to estimate house prices from housing attributes through data preprocessing, visualization and regression models.

## Features

- Data cleaning
- Missing value handling
- Feature engineering
- Correlation analysis
- Regression model comparison
- Model evaluation

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Models Used

- Random Forest Regressor
- Gradient Boosting
- XGBoost Regressor

## Evaluation Metrics

- MAE
- MSE
- RMSE
- R² Score
